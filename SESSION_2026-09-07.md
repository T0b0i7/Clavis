## 1. Diagnostic — Bug mobile (ROOT CAUSE)

**Symptôme :** Sur téléphone, le chrono tourne mais impossible de taper.

**Cause technique :**
- `components/typing/typing-test.tsx` : `<input>` en `opacity-0` avec `onChange={() => {}}` vide
- Toute la logique dans `onKeyDown` (`e.key`)
- Claviers virtuels Android/iOS n'envoient PAS de `keydown` fiable :
  - `e.key = "Unidentified"` / `229`
  - Événements `input` / `beforeinput` avec `insertText`, `deleteContentBackward`
  - Autocorrect insère des mots entiers
- Input dans `overflow-hidden` → iOS ne lève pas le clavier (clippé)
- `font-size < 16px` → zoom iOS qui casse le focus
- Overlay `!isFocused` avec seul `onClick` → pas de `onTouchEnd`

**Fichiers concernés :**
- `components/typing/typing-test.tsx`
- `hooks/use-typing-test.ts`

---

## 2. Fix appliqué

### `hooks/use-typing-test.ts`
- Ajout `isComposingRef` + `handleCompositionStart/End` (accents FR é è à)
- Extraction `ensureStarted()` factorisé (démarre chrono depuis mobile ET desktop)
- Nouveau `handleInputChange(e)` pour clavier virtuel :
  - Diff `newValue` vs `typed`
  - `inserted.includes(" ")` → validation mot (comme Space)
  - `newValue.length > typed.length` → insertion normale + `recordKeyResult` + `onWrongKey`
  - `newValue.length < typed.length` → backspace + `correctedErrorsRef`
  - `same length` → autocorrect/replacement
  - Auto-finish dernier mot sans espace (mode words/quote/learn)
- Exposé : `handleInputChange`, `handleCompositionStart`, `handleCompositionEnd`

### `components/typing/typing-test.tsx`
- Input déplacé HORS du `overflow-hidden` :
  ```tsx
  <div className="relative w-full rounded-[12px] focus-within:ring-2 ...">
    <input className="absolute inset-0 z-10 h-full w-full opacity-[0.01]"
           inputMode="text" enterKeyHint="done"
           style={{fontSize:"16px"}}
           onChange={handleInputChange}
           onCompositionStart/End
           onKeyDown={handleKeyDown} />
    <div ref={wordsContainerRef} className="h-[7.8rem] overflow-hidden">...
  ```
- Overlay `!isFocused` : ajout `onTouchEnd` + `touch-manipulation`
- Message PC-first dans overlay :
  ```
  Appuie pour faire apparaître le clavier
  💻 Clavis est bcp mieux sur PC — pas fait pour mobile
  ```
- Banner mobile sous chrono :
  ```tsx
  <div className="flex md:hidden">
    <span>💻 Clavis est bcp mieux sur PC — pas optimisé pour mobile</span>
  </div>
  ```
